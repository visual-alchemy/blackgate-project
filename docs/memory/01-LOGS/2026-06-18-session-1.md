# Session Log: 2026-06-18 - Session 1 (GCP Migration & SRT Proxy)

## Sprint Goal & Focus
Migrate Blackgate to run on GCP cloud environments. Remove hardware-dependent SDI destinations and implement single-port SRT multiplexing using StreamIDs.

## What Was Accomplished

### 1. Legacy Branch Cleanup
- Checked git branches and verified that the `sdi-output` branch has been fully merged into `rtmp-ffmpeg`.
- Removed old/obsolete branches both locally and on origin:
  - `rtmp-support` (deleted)
  - `rtmp-pull` (deleted)
  - `sdi-output` (deleted)
- Created and checked out new branch `gcp-ready` from `rtmp-ffmpeg`.

### 2. SRT Proxy C Binary (`srt_proxy`)
- Developed a lightweight C-based SRT proxy `native/src/srt_proxy.c` using `libsrt` and `libcjson`.
- Proxy listens on public port `9999`.
- When an external client connects as caller, proxy accepts, extracts the client's `streamid`, and looks it up in `/tmp/srt_routes.json`.
- If mapped to an internal port (e.g. `39100`), proxy initiates connection as caller to `127.0.0.1:39100` (where GStreamer listens) and bridges bidirectional traffic in separate parallel threads.
- Sockets are automatically closed and resources cleaned up on exit.
- Updated `native/Makefile` to build both `blackgate_pipeline` and `srt_proxy` binaries separately.

### 3. Elixir Backend Integration
- Created GenServer `Blackgate.SrtProxy` in `lib/blackgate/srt_proxy.ex` to manage `srt_proxy` lifecycle. It spawns the proxy process, restarts it if it crashes, and writes `/tmp/srt_routes.json` dynamically.
- Registered `Blackgate.SrtProxy` in `lib/blackgate/application.ex` supervision tree.
- Updated `lib/blackgate/route_handler.ex`:
  - Added a guard in `handle_event(:internal, :start)` that checks for any SDI destinations and aborts route startup with an error status.
  - Added `maybe_setup_srt_proxy` to intercept SRT listener sources. If configured with a `streamid`, it allocates an internal loopback port, registers it with `Blackgate.SrtProxy`, and binds GStreamer's source to `127.0.0.1:internal_port`.
  - Cleans up proxy mappings in `terminate` callback on route shutdown.

### 4. UI Hiding
- Modified `web_app/src/pages/routes/RouteDestEdit.jsx` to hide the "SDI" destination type option from Destination options, preventing new SDI destinations from being created.

### 5. Verification & Testing
- Built C binaries successfully (`make -C native`).
- Compiled Elixir app successfully (`mix compile`).
- Started backend locally, verified `srt_proxy` starts up, registers test routes to `/tmp/srt_routes.json` via remote RPC, and routes streams correctly end-to-end using `srt-live-transmit`.

## Key Decisions & System Constraints
- **Keep Codebase Compile-Safe:** The C engine (`gst_pipeline.c`) still contains DeckLink elements but imports them dynamically. It compiles cleanly on macOS/GCP Linux instances without hardware presence.
- **Port Multiplexing Isolation:** Multiplexing is done via a standalone C proxy using `/tmp/srt_routes.json` as the routing table. This preserves the isolated one-OS-process-per-route architecture of Blackgate.
