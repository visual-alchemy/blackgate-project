## Key Decisions & System Constraints Resolved

- Failover Mode controls source preference; Auto Join controls whether both
  source branches stay warm; Seamless SDI Failover controls whether an SDI cut
  occurs inside the live pipeline.
- Auto Join alone cannot retain encoder sessions across restart fallback because
  both `srtsrc` listener sockets live inside the restarted native process.
- Seamless mode is appropriate for current clients because codec, profile,
  resolution, frame rate, scan mode, audio format, and MPEG-TS layout match.
- Brief freeze up to target-keyframe/decoder recovery time is expected. Black,
  encoder reconnection, or multi-second interruption indicates restart fallback
  or another fault.
- Arbitrary-format switching remains out of scope until a real client requires
  PID remapping or demux/remux normalization.
- No credentials, passphrases, tokens, or complete secret-bearing SRT URIs were
  recorded in diagnostics or documentation.
