## Root Cause Analysis & Next Steps Hypothesis (Titan Edge vs Blackgate)

- **Titan Edge Comparison**:
  - Harmonic Titan Edge hardware IRD only requires `SRT Listener`, `Port`, and `Passphrase` (no `streamid`) to ingest the real ATP feed.
  - Titan Edge auto-detects key length and parses raw passphrase strings directly without URL query parsing.

- **Hypothesis 1 — Passphrase Special Character URI Truncation in GStreamer**:
  - Passphrase contains `%` and `&` (`K5894^#%Hk6LkKAxmS&Z*a`).
  - In GStreamer `srtsrc`, passing unencoded `&` in `uri="srt://0.0.0.0:12015?passphrase=K5894^#%Hk6LkKAxmS&Z*a"` causes GStreamer's URI parser to treat `&Z*a` as a separate URL query key, truncating the passphrase to `K5894^#%Hk6LkKAxmS`.
  - When the real ATP source negotiates AES decryption with the full passphrase, GStreamer fails key decryption, producing `Application-defined rejection reason`.

- **Hypothesis 2 — `pbkeylen` Auto-Detection in C Engine**:
  - Titan Edge auto-negotiates 16/24/32 byte AES key length, whereas GStreamer requires explicit `pbkeylen` configuration.
