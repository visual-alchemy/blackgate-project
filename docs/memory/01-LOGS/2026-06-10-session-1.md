# Session Log: 2026-06-10 - Session 1

## Sprint Goal & Focus
Diagnose and resolve the physical SDI audio silence on BWF Courts 1-4 and silence the InfluxDB `econnrefused` log flood on the remote gateway.

## What Was Accomplished

### 1. InfluxDB Log Flood Silence
* **Identified** that every stats collection tick was attempting to write to `Blackgate.Metrics.Connection` (Instream). Since InfluxDB is not configured or running in this environment, it threw connection refused errors (`%WithClauseError: {:connect_error, {:error, :econnrefused}}`) which flooded the system journal.
* **Modified** [metrics.ex](file:///Users/eldyreynanda/Developer/Antigravity/blackgate-project/lib/blackgate/metrics.ex) to check `Application.get_env(:blackgate, :export_metrics?, false)` before attempting to write events.
* **Compiled** the code, transferred the new `.beam` file to the remote gateway release, and hot-loaded the `Blackgate.Metrics` module into the running BEAM VM via RPC.
* **Verified** that the log spam has completely stopped and the journal is now clean.

### 2. BWF Court SDI Audio Silence Resolution (8-Channel Mirroring & Positioned Mask)
* **Identified** that the previous `first-channels` upmix mode in `gst_pipeline.c` only mapped input channels 1/2 to output channels 1/2, leaving output channels 3-8 silent. Since the downstream SDI switchers for Courts 1-3 monitor other channel pairs, they output silence.
* **Implemented** a custom 8x2 transformation matrix using the GStreamer GValue array API in [gst_pipeline.c](file:///Users/eldyreynanda/Developer/Antigravity/blackgate-project/native/src/gst_pipeline.c) in `manual` mode.
* **Discovered** that in `manual` mode, `audiomixmatrix` defaults the output channel layout to `channel-mask=0` (unpositioned). When the DeckLink driver receives unpositioned audio, it drops or mutes it on the physical SDI embedder.
* **Resolved** this by explicitly configuring the `channel-mask` property on `audiomixmatrix` to `(guint64)0xc3f` (default 8-channel mask) and setting it in the downstream `acaps` capsfilter string. This forces GStreamer to output a correctly positioned 8-channel stream.
* **Compiled** the C engine on the gateway and hot-swapped the binary.
* **Performed a Clean Sweep** of 28 orphaned `ffmpeg` sidecar processes on the remote gateway that had leaked and bound loopback UDP ports.
* **Restarted** BWF Court routes 1-4 via Elixir RPC. Verified that they initialized and started successfully.

### 3. Loopback Port Allocation Safety (UDP & TCP Verification)
* **Identified** that Elixir's `find_available_port/1` was checking port availability by listening on TCP (`:gen_tcp.listen`). Since the loopback SRT sidecar operates over UDP, checking only TCP allowed Elixir to allocate ports that were secretly occupied by orphaned UDP `ffmpeg` processes, leading to bind conflicts.
* **Modified** [route_handler.ex](file:///Users/eldyreynanda/Developer/Antigravity/blackgate-project/lib/blackgate/route_handler.ex) to check both TCP (`:gen_tcp.listen`) and UDP (`:gen_udp.open`) port availability before returning a port.

## Key Decisions & System Constraints Resolved
* **Channel Duplication/Mirroring:** Opted to mirror the stereo source channels to all 8 output channels. This ensures that downstream equipment will receive audio regardless of which channel pair it is configured to monitor.
* **Explicit Channel Masking:** Discovered that DeckLink requires a standard positioned channel mask (`0xc3f`) to successfully embed and play out multi-channel audio over SDI.
* **Zero-Downtime Swap:** Handled the C binary hot-swap by unlinking the file, ensuring that the long-running production routes (Magna TV and NTV) remained completely uninterrupted.
