### 2. Green Macroblocking Diagnosis
- **Symptom:** Occasional green macroblocks visible on client player (OBS/VLC).
- **Diagnostics:**
  - Checked input loopback stats: `packets-received-lost` and `packets-received-dropped` are exactly **0**. Input link is perfectly clean.
  - Checked output SRT sink stats: `packets-sent-lost` is **5.8%** on Court 1 and **8.5%** on Court 2. Packet loss on output transmission is causing skipped slices/key frames.
- **Root Cause:** 
  - GStreamer's `srtsink` does not expose `rcvbuf` or `sndbuf` as element properties (only as URI parameters). Our codebase previously failed to append them to the SRT URI.
  - Fix has been pushed to append `sndbuf`, `rcvbuf`, `oheadbw`, and `maxbw` directly to the SRT URI query parameters.
  - **OS Level Limit:** Running `sysctl net.core.rmem_max net.core.wmem_max` on the remote gateway returned **`212992` (208 KB)**.
  - The small default OS UDP buffer limit caps SRT sockets at 208 KB, causing instant UDP socket overflows and packet drops under 9–14 Mbps bitrates.
