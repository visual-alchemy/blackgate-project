# 2026-09-01 — Session 1: Failover Audit Remediation

## Goal

Verify reported failover defects on `feat/srt-failover`, then implement fixes on
the user-designated sandbox gateway without restarting services or changing
system configuration.

## Implemented

- Corrected GStreamer 1.24 `srtsrc::caller-connecting` callback ABI and removed
  stream-ID value logging.
- Cleared dead native Port state before recovery; ignored delayed data from
  replaced Ports.
- Preserved logical primary/secondary slots. Init payload now includes persisted
  `active_source`; native selector starts on that pad without duplicating or
  swapping source configs.
- Locked `auto_join=false` secondary child at NULL. Native switch starts it
  before selecting secondary and selects primary before stopping it.
- Set `input-selector sync-streams=false`; corrected `sync-mode=0` semantics.
- Added newline framing, full-write retry, write serialization, and prefixed
  atomic frames to native Unix socket transport. Ranch receiver now uses binary
  line packets with 1 MiB limit. Native socket tests use isolated temporary
  sockets instead of live `/tmp/hydra_unix_sock`.
- Delayed `active_source` persistence until native `SOURCE_SWITCHED` or
  `PIPELINE_READY` acknowledgement. Added persistence retry and missing-switch-
  ACK fallback to restart.
- Forced SDI source changes through restart path. In-process raw MPEG-TS switch
  remains enabled only for non-SDI dual-SRT routes.
- Added backend SRT/failover validation plus matching form rules.
- Removed Docker dependency on ignored `deps/`; fresh image fetches Mix deps.
- Made `authFetch` reject all non-2xx responses. Route detail polls active
  failover routes while started or reconnecting.
- Redacted native/backend URI, passphrase, stream-ID, init JSON, route-record,
  and FFmpeg source URL logs. Removed browser route-data console dump.
