## 🔍 Key Findings & Discussion

### 1. DeckLink Hardware Specification
- **Hardware Card:** Blackmagic DeckLink Quad 2 (PCIe card).
- **Capacity:** 8 configurable SDI input/output channels.

### 2. SMPTE ST 2022-6 vs SMPTE ST 2110
- **SMPTE ST 2022-6 (Legacy / Muxed IP):**
  - Published ~2012. Wraps entire SDI signal (video + embedded audio + metadata) into IP packets.
  - Inflexible (must transfer whole 3 Gbps stream even for audio-only access).
  - Supported in GStreamer via `gst-plugins-bad` (`rtp2022pay`, `rtp2022depay`, `rtpsdimux`).
- **SMPTE ST 2110 (Modern / Separated IP):**
  - Published ~2017+. Splits streams into independent flows (ST 2110-20 video, ST 2110-30 audio, ST 2110-40 metadata).
  - Synced using IEEE 1588 PTP (Precision Time Protocol).
  - Highly flexible & network efficient.
  - Supported in GStreamer via `rtpvrawpay`, `rtpL24pay`, `GstPtpClock`, and hardware plugins (e.g., `gst-rivermax`).

### 3. Blackgate SMPTE ST 2110 Roadmap Requirements
- **Hardware:** 25G/100G PTP-aware NICs (e.g., NVIDIA ConnectX-6/7), PTP Grandmaster Clock server, PTP-aware network switches.
- **Host Software:** `linuxptp` daemon (`ptp4l`, `phc2sys`), NVIDIA Rivermax SDK kernel bypass.
- **Native C Engine:** Pipeline support for `rivermaxsrc`/`rivermaxsink` or `rtpvrawdepay`/`rtpL24depay`, PTP clock binding, SDP file parser.
- **Elixir Core:** `st2110_in` and `st2110_out` route schemas, Khepri SDP storage, optional NMOS (IS-04/IS-05) control API.
- **React Frontend:** PTP sync status UI, SDP import/export, interface mapping.
